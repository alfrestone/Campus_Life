# 🎓 Campus Life

## 📖 Description
**Campus Life** is a front-end web development project focused on recreating a Figma design using pure HTML and CSS.
## 🛠️ Technologies Used
- **HTML5**: For semantic and structured page content.
- **CSS3**: For styling, layout Flexbox(Not responsive yet).
- **Figma**: Original design source.
- **Git & GitHub**: hosting via GitHub Pages.

## 📂 Project Structure
The project is organized to keep assets, styles, and pages separate and manageable:

```text
Campus_Life/
├── index.html          # Home page
├── css/
│   └── style.css       # Main stylesheet for all pages
├── assets/

│   └── icons/          # Project icons
└── README.md           # Project documentation
